# EVA WEB 3D Field Research

This directory stores **candidate knowledge** gathered by narrow field-research cycles before Claude cross-model audit and Research Bible normalization.

Nothing in this directory is promoted to canon by default.

Evidence classes used here:

- `CANON_EXPLICIT`
- `OFFICIAL_META`
- `VISUAL_OBSERVATION`
- `SECONDARY`
- `INFERENCE`
- `ESTIMATE`
- `UNKNOWN`

Each finding should separate continuity, source quality, confidence, scale status, and 3D-production implications.
