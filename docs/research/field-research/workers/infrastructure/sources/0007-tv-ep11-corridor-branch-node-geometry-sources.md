## Image-search note

Image search was performed for Episode 11 corridor/branch imagery. Public results reliably surfaced the R-07 manual door and generic corridor views, but no clean, well-attributed image of the exact right/left branch point was found. No screenshot or copyrighted production frame was downloaded or stored in the repository workspace.

Accordingly, this cycle does **not** claim a T-shaped, Y-shaped, 90-degree, symmetric, or otherwise specific branch plan from visual evidence.

## Evidence conclusion

Supported at medium-to-high confidence through multiple independent secondary transcriptions:
- the pilots encounter an explicit two-branch decision node;
- one option is right and one is left;
- the chosen right route rises;
- that route reaches an exterior-facing door / Angel encounter;
- a later branch-choice scene occurs again.

Plausible but not verified:
- the original left branch is the correct uninterrupted route toward Headquarters;
- the later branch is the same node revisited.

Unresolved:
- exact branch plan geometry;
- branch angles and dimensions;
- wall/ceiling section at the node;
- signage and markings;
- exact distance/elevation from R-07;
- exact node identity across the two branch scenes.
