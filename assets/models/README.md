# EVA GLB assets

## Active runtime hero

- `eva-unit-hero.glb.gz` — gzip-compressed M3 Web GLB used by the browser.
- `eva-unit-hero.glb` — uncompressed M3 GLB for inspection, Blender import, and downstream authoring.
- Both are generated by `scripts/generate-eva-runtime-glb.py`.
- Runtime loading uses `DecompressionStream('gzip')` and `GLTFLoader.parseAsync()`.
- The GLB uses shared mesh definitions with node instancing, layered PBR materials, and separate armor/joint/service parts.
- The loader strips generator template nodes, fits the visible model to `EVA_HEIGHT`, and hides the procedural fallback only after successful load.
- Dorsal Entry Plug geometry remains centered on the upper-back / neck region.

The authored M3 modeling specification is `docs/design/eva-cage/eva-unit-mesh-spec.md`.
